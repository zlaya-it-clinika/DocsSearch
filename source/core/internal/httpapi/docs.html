DocsSearch API

Запросы уходят на этот же сервер. В заглушке: user / user и admin / admin.

POST/auth/login

Вход сотрудника. Токен из ответа подставится в поле выше.


		


		

			
GET/me

			
Текущий пользователь без токена в теле ответа.

			
			
			

		


		

			
POST/sessions

			
Новая сессия. Ее id подставится в запросы истории и сообщений.

			
			
			

		


		

			
GET/sessions/{sessionId}

			
История сессии.

			
			
			

		


		

			
POST/sessions/{sessionId}/messages

			
Фразы заглушки: нет доступа, не найдено, уточни, шаблон. Иначе обычный ответ.

			
			
			
			

		


		

			
GET/documents

			
Только документы не выше уровня пользователя.

			
			
			

		


		

			
POST/documents

			
Загрузка в базу. Файл в заглушке не индексируется, но появляется в списке.

			
			

				
				
				
				
			

			
			

		


		

			
GET/documents/{documentId}/file

			
Файл оригинала. doc-2 закрыт для user.

			
			
			

		


		

			
GET/users

			
Список учетных записей. Нужен уровень 2.

			
			
			

		


		

			
POST/users

			
Создание учетной записи. Нужен уровень 2.

			
			
			
			

		


		

			
PATCH/users/{userId}

			
Смена имени и уровня. Нужен уровень 2.

			
			
			
			

		


		

			
GET/audit

			
Журнал вопросов. Нужен уровень 2.

			
			
			

		


		

			
POST/drafts/check

			
Проверка черновика. В заглушке одна фиксированная рекомендация.
